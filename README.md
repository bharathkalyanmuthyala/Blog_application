📝 Student Blog Application

A MERN Stack-based web application that enables students and authors to engage through blogging.
Students can explore and comment on blogs, while authors can create, manage, and interact with readers through comments.

🚀 Features
👩‍🎓 Student

Register and log in securely.

Browse all blogs posted by authors.

Read full blog content.

Comment on blogs to share opinions or ask questions.

✍️ Author

Register and log in securely.

Create, edit, and delete blog posts.

View all comments from students on their blogs.

⚙️ Common Features

User authentication with JWT (JSON Web Token).

RESTful API integration for communication between frontend and backend.

Responsive UI built with React.

MongoDB for storing users, blogs, and comments.

🧩 Tech Stack
- Layer	Technology
- Frontend	React.js, HTML5, CSS3, Bootstrap
- Backend	Node.js, Express.js
- Database	MongoDB (Mongoose ODM)
- Authentication	JWT (JSON Web Token)
- Server	Express.js Server (server.js)
- Tools	Postman, VS Code, Git
